## mxi import

NXmx files to an experiment list.

```
usage: mxi import MASTER [MASTER ...] [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
  An experiment list -- beam, detector, goniometer, scan, image set -- from
  NXmx HDF5 master files, as dials.import writes it: one experiment a
  master, each sweep with models of its own. The options apply to every
  master alike.
  -o, --output PATH     where to write it: a .rflx (imported.rflx), or an
                        .expt, JSON, as dials.import writes it
  --wavelength A        the wavelength, for a file without or with a wrong one
  --distance MM         the detector distance, along the panel's normal
  --beam-centre X,Y     where the beam meets the detector, in pixels, fast and
                        slow: the detector moved in its plane to put it there
  --mu M                the sensor's attenuation coefficient, 1/mm, for a
                        material not tabulated
  --trusted-max N       the top of the trusted range, for a file with no
                        saturation value
  --image-range A,B     only images A to B, counting from 1
  --split N             each sweep as N sweeps of consecutive images, as
                        even as they can be: partials at the joins, a big
                        set as many small ones, for testing
```

## mxi find

spots, on the CPU or a GPU.

```
usage: mxi find IMPORTED.rflx [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
       mxi find MASTER.nxs [options]

Strong spots on every image of every sweep: the input an experiment
list, as mxi import writes it (or a DIALS .expt), naming where each
sweep's images are; or an NXmx master file directly.

  -x MASTER.nxs      the images, where the experiment list's are moved
  -o file            where to write: a .rflx, with the experiment list
                     if one was given (strong.rflx), or a .refl, the
                     reflection table alone
  --timing           where the time goes: each stage's time summed across
                     the threads, against the time they had
  --verbose          the run's particulars as well: the images, the
                     series, threads, mask and grouping
  -g, --gpu          run the threshold on the GPU; 16-bit only under
                     Metal, which has no double precision
  --gpu-force        32-bit frames narrowed to 16 bits, so that a GPU of
                     16 bits only takes them: the bad-pixel and
                     the 16-bit one, every other count as it is, stopping at
                     one of 0xFFFD or more. mxi max says whether a series
                     fits. The same spots as the 32-bit threshold
  --no-shoeboxes     leave out the pixel data, which is most of the
                     file and is not needed for indexing
  --min-spot-size N  contiguous pixels a spot needs (3)
  --max-spot-size N  and the most it may have (1000)
  --max-separation D peak to centroid, in pixels; 0 turns it off (2)
  --subtract-background
                     centroids weighted by count less the threshold's local
                     background, the intensity less it, and the background
                     kept in the shoeboxes, where the integrator's profile
                     model uses it; off, as DIALS has it
  --2d               group each frame on its own, as for stills
  --z-offset N       array index of image number 0; taken from the
                     experiment list when one is given, and 0 otherwise
  --chunk N          frames held between groupings (a few per thread)
  --progress-from N  a progress bar from N images (100); a line each
                    tenth where the output is not a terminal
  -t timeout         seconds to wait for the file to appear (default 60)
  -p poll-ms         interval between checks while waiting (default 200)
  --version          what this binary is, and what it was built with
```

## mxi index

a lattice for the spots.

```
usage: mxi index IMPORTED.expt STRONG.refl [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
  --d-min D        resolution limit (default: from the data)
  --max-cell A     longest cell edge (default: from spot spacing)
  --known-cell a,b,c,alpha,beta,gamma  the cell the crystal is known to
                   have: the basis chosen from those matching it (10
                   per cent, 5 deg), as dials.index unit_cell=
  --real-space-grid  the basis vectors found by the real-space grid
                   search (Gildea et al. 2014) rather than the 3D FFT:
                   the known cell's edge lengths in every direction --
                   needs --known-cell; for sparse or multi-lattice data
  --grid-step DEG  its directions' spacing (1.15, dials.index's)
  --known-space-group NAME  the known cell's setting, by its lattice
                   letter (P by default): I213 for a 78 A body-centred cube
  --grid N         FFT grid size, power of two (default: from d_min)
  --timing         where the time went, by phase
  --tolerance T    how far an index may fall from an integer (0.3)
  --candidates N   basis vectors taken from the peak list (30)
  -o PATH           where to write: one .rflx (indexed.rflx), or with
                    a .refl the DIALS pair, as --output-expt, -refl
  --output-expt P   the DIALS pair's experiment list (indexed.expt)
  --output-refl P   the DIALS pair's reflections (indexed.refl)
  --macrocycles N  assign/refine/re-assign cycles (3)
  --max-lattices N  look for up to N lattices in one sweep -- crystals
                    side by side in the beam -- each its own experiment,
                    sharing the sweep's beam and detector (1)
  --min-lattice-spots N  the fewest spots a lattice may index (50)
  --ambiguous exclude|closest  a spot more than one lattice indexes:
                    left out of refinement, unindexed (exclude), or
                    given to the lattice it lies nearest (closest)
  --no-keep-sweeps  the lattices alone; by default each sweep given is
                    carried through first, crystal-less, its unindexed
                    spots its own, the lattices after it
                    (dials/dials#1029)
  --ambiguity-sigma S  ambiguous: within S of each lattice's own RMS
                    scatter of a second lattice's point (3)
  --no-joint        several sweeps, each indexed on its own -- a crystal
                    of its own, as dials.index joint=false: many
                    crystals, which share no matrix
  --shared-crystal  several sweeps: one crystal throughout, where by
                   default the last cycle refines each sweep's apart
  --all-reflections  refine on everything, not the stronger half
  --verbose         also print the search: candidate vectors, the fit
                    at each tolerance, and the cell before reduction
  --quiet           accepted for older scripts; the search is no
                    longer printed unless --verbose asks for it
```

## mxi refine

the models against the spots.

```
usage: mxi refine INDEXED.expt INDEXED.refl [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
  --no-crystal      hold the crystal fixed
  --no-detector     hold the detector fixed
  --no-beam         hold the beam direction fixed (refined by default;
                    on a single sweep it is correlated with the
                    detector)
  --joint           several sweeps refined in one fit, sharing what
                    models they share, where by default each sweep is
                    refined on its own
  --shared-crystal  several sweeps: one crystal for them all, where by
                    default each refines its own (--separate, as was)
  --conditional-depth  mean depth given absorption, not eqn (6)
  --scan-varying [N]  control points in A across the scan. Scan-varying
                    is the default, one per 10 degrees and at least five,
                    on a scan of 10 degrees or more; N sets the number
  --interval DEG    scan-varying control points one per DEG degrees of
                    each sweep (10, at least five by default; at least
                    four here) -- 20 or 30 for sparse data
  --sample-offset   the centre of diffraction off the rotation axis,
                    turning with the crystal: two parameters a lattice
                    (amplitude and phase), where the crystal is not
                    centred or the beam not on it
  --crystal-restraint W  each control point's A tied to the static A, a
                    prior of about 1/sqrt(W) of A's size: where the
                    reflections hold a point it is theirs, where they do
                    not the crystal stays static (1e6; 0 for none)
  --static          a crystal that does not move: one A for the scan
  --unit-weights    ignore the centroid variances
  --strong-only     build the model from the stronger half only
  --numerical       finite differences, not the analytical derivatives
                    (the default), for testing
  --timing          where the time went, by phase
  --detector-in-scan-varying  keep refining the detector during the
                    scan-varying pass; it is degenerate with the cell
  --min-volume V    drop reflections whose rotation angle is not
                    determined by the data; 0 keeps them all (0.05)
  --z-weight W      scale the weight on the rotation-angle residual
  --macrocycles N   (3)
  --outlier-sigma S (4; 0 disables rejection)
  -o PATH           where to write: one .rflx (refined.rflx), or with
                    a .refl the DIALS pair, as --output-expt, -refl
  --output-expt P   the DIALS pair's experiment list (refined.expt)
  --output-refl P   the DIALS pair's reflections (refined.refl)
```

## mxi integrate

the reflections' intensities.

```
usage: mxi integrate [options] EXPT [INDEXED_REFL]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)

  -o FILE           where to write: one .rflx (integrated.rflx) of the
                    reflections, the models and the profile model used;
                    or with a .refl the DIALS pair, the .refl that
  --output-expt PATH   the DIALS pair's experiment list (integrated.expt)
  --images PATH     the image file; by default the .expt's own
                    imageset template is used
  --postrefine      integrate, refine against the centres integration
                    measured, and integrate again with the refined
                    models, which are what --output-expt then holds.
                    Removes the z offset the spot finder's centres
                    leave in a refined model
  --postrefine-points N   control points for its scan-varying pass;
                    default one per 10 degrees, at least 5, as
                    mxi refine --scan-varying
  --sigma-b B --sigma-m M   profile model. Estimated from INDEXED_REFL
                    if given -- indexed or refined reflections, not a
                    spot finder's -- else taken from EXPT's profile block
  --sigma-m-estimator basic|extended  sigma_m with each image holding
                    foreground counted once (basic, the default, as
                    DIALS's) or weighted by its counts (extended)
  --n-sigma N       foreground spans plus and minus N sigma (3)
  --box-scale S     box is S times wider than the foreground (1.9)
  --min-zeta Z      skip reflections nearer the rotation axis than this
                    (0.05, as DIALS): no box, no reading, no part in the
                    profile model. A reflection's extent in phi goes as
                    1/|zeta|, so the smallest are forty images deep. 0.2 to
                    0.3 for several sweeps of a small molecule: a fifth of
                    the outliers against Fc^2, no unique reflection lost
  --d-min D         resolution limit
  --d-max D         low resolution limit: nothing integrated with d above
                    D A -- reflections beside a backstop, say
  --first-image N --last-image N   restrict to part of the scan
  --gain G          detector gain, counts per photon (1)
  --save-background-parameters
                    also write each reflection's background dispersion,
                    variance over mean, over every background pixel and
                    trimmed, with how many pixels: under investigation
  --save-shoeboxes  keep the pixels and the mask in the output
  --window N        frames read per chunk (64); boxes stay open across
                    chunks, so this bounds memory, not re-reading
  --max-boxes N     boxes opened per chunk (6000 a thread, at least
                    20000); shortens the chunk
                    when it bites, about 31 kB a box
  --summation-only  skip profile fitting
  --no-mask-neighbours  leave each reflection's neighbours in its
                    background: by default, their foregrounds are
                    masked out of it, any lattice's, as DIALS's
                    3d_threaded integrator does
  --no-fit-overlaps  fit each reflection alone: by default, those
                    whose foregrounds overlap, of any lattice, are
                    profile fitted together, each its own profile, the
                    shared pixels apportioned between them, and their
                    summed intensities corrected (docs/integration.md)
  --fit-overlaps    the default, as above: accepted, for what asks for it
  --each-alone      the lattices of a sweep a run each, reading its
                    images once a lattice, rather than in one pass
  --two-pass        read the images twice, to learn and then to fit, as
                    before one pass; the same answer, byte for byte
  -g, --gpu         profile fitting on the GPU, in single precision; the
                    CPU's is in double. One pass only
  --gpu-emulate     the same single-precision fitting on the CPU, for
                    testing without a device
  --grid-points N   the profile grid is 2N+1 a side (6)
  --subdivisions N  pixel subdivisions per axis (5, as Kabsch uses)
  --regions N       detector divided N by N for reference profiles (3)
  --scan-blocks N   the scan divided N ways as well (one per 10 degrees)
  --reference-signal S   learn from reflections above S sigma (10)
  --least-measured F  a fit needs this fraction of the reflection to
                    have been recorded (0.6); below it the intensity is
                    written but not flagged as fitted
  --save-profiles F the learned reference profiles, as text; several
                    sweeps a file each, F_0, F_1 before F's extension
  --timing          where the time went, by phase
```

## mxi scale

scaled and merged intensities.

```
usage: mxi scale [options] INTEGRATED_EXPT INTEGRATED_REFL
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
  --space-group NAME  the space group, "I 2 3" or "197"; default the
                    crystal's own
  --change-of-basis CB   to that group's setting first, in DIALS'
                    notation: "b+c,a+c,a+b" from the primitive cell of
                    a body-centred cubic lattice
  --d-min D         leave out reflections beyond D A; the summary then has
                    no Suggested column
  --exclude E:FIRST:LAST  experiment E's images FIRST to LAST left out
                    (or E:FIRST-LAST), as dials.scale's exclude_images;
                    as many as wanted. A sweep's crystal-less experiment
                    stands for its lattices
  --d-max D         leave out reflections with d above D A: a low
                    resolution limit
  --d-min-auto      scale everything, estimate the limit from CC half, and
                    scale again to it, if CC half falls to the limit
                    within the data at all
  --cc-half-limit C   the CC half the limit is set at (0.3)
  --anomalous       Friedel mates apart: I(+) and I(-) of an acentric
                    reflection scaled, given their error model and
                    rejected as outliers as separate groups, for data
                    with a strong anomalous signal. The merging table is
                    the same groups either way
  --no-absorption   no absorption surface, whatever the sweep
  --error-model-fit F  regression (by regression across intensity
                    bins) or individual (a and b in turn, as
                    dials.scale's default)
  --no-model-variances  each observation's variance as integrated, not
                    built on the model's intensity (docs/scaling.md)
  --absorption-level LEVEL
                    as dials.scale's: low (the default) for ~1% relative
                    absorption -- degree 4, restraint 5e5; medium for ~5%
                    -- 6, 5e4; high for >25%, long wavelengths or heavy
                    absorbers -- 6, 5e3
  --l-max L         the absorption surface to degree L, lmax (lmax + 2)
                    terms: 4 by default from 60 degrees (24), 6 for 48
  --scale-restraint W  each sweep's scale tied to a constant, its own
                    level, with weight W -- a prior of about 1/sqrt(W):
                    where the data hold the scale it is theirs, where
                    they do not it stays level (1; 0 for none)
  --decay-restraint W  each relative B tied to zero with weight W
                    (0.1, dials.scale's)
  --profile-only    profile-fitted intensities alone, not a mix with
                    summation chosen by Rmeas
  --shells N        resolution shells in the table (20)
  -o PATH           where to write: one .rflx (scaled.rflx), or with a
                    .refl the DIALS pair, its .expt at --output-expt
  --output-expt PATH   the DIALS pair's experiment list (scaled.expt)
  --timing          where the time goes
```

## mxi export

MTZ and the like.

```
usage: mxi export [options] FILE.rflx | EXPT REFL
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
  An unmerged MTZ, as dials.export writes one: a row an observation, a

  --project-name NAME        (mxi)
```

## mxi process

every step above in turn, import to export.

```
usage: mxi process MASTER.nxs... [options]
       mxi process FILE.rflx [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
The whole sequence, a step at a time: mxi import, find, index, refine,
integrate, symmetry, scale and export, each on the file the one before
wrote, as a script of them would run them. Stops at a step that fails,
saying which, its log, and the command to run it again.
Or given one .rflx, it picks up after the step that wrote it and
finishes: a cluster from mxi correlation --write-clusters is scaled and
exported; strong.rflx is indexed, and so on.
  -j N              to every step
  --gpu             spot finding and integration on the GPU
  --cell a,b,c,alpha,beta,gamma   the known cell: mxi index --known-cell
  --no-joint        several sweeps, each a crystal indexed on its own:
                    mxi index --no-joint
  --small-molecule  every space group, centrosymmetric too:
                    mxi symmetry --small-molecule
  --space-group NAME  the known space group: mxi scale --space-group, and
                    with --cell, mxi index --known-space-group
  --d-min-auto      mxi scale --d-min-auto: the limit from CC half
  --dry-run         the commands, printed; nothing run
  --timing          to every step that times itself (find to scale),
                    and at the end each step's time, import and export
                    too
```

## mxi correlation

crystals clustered, as cosym.

```
usage: mxi correlation SCALED.rflx [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
       mxi correlation SCALED.expt SCALED.refl [options]

The correlation of every pair of data sets -- each lattice of a scaled
file -- weighted by the intensities' uncertainties, as
dials.correlation_matrix: the first stage of clustering them.

  --min-partiality P  reflections at least this partial (0.4)
  --min-pairs N       a pair's correlation needs N reflections in common (3)
  --no-normalise      correlate the data sets as scaled, not each first
                      normalised by its own Wilson fall-off
  --dimensions N      the cosym coordinates in N dimensions (by default
                      the elbow of the functional over 1 to
                      min(n, 50), as dials.correlation_matrix)
  --by-projection     the functional for each dimension from one
                      minimisation, projected (DIALS #3248): faster
  --xi X              OPTICS's steepness for a cluster's edge (0.05)
  --max-distance D    OPTICS's max_eps (0.5, as DIALS's)
  --min-samples N     OPTICS's min_samples, not searched for
  --html FILE         the report (mxi_correlation.html): the matrices with
                      their dendrograms, the reachability plot, the
                      principal components, the dimension functional
  --write-clusters    each cluster as its own .rflx, PREFIX_0.rflx and
                      on: its data sets and their reflections, for
                      mxi scale
  --prefix PREFIX     those files' names (cluster)
  --json FILE         the matrix, its weights, the data sets, the
                      coordinates and their principal components
  -h, --help          this
```

## mxi triage

twinning and the intensities' statistics, as xtriage.

```
usage: mxi triage SCALED.rflx [options]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
What the scaled intensities say of twinning, as phenix.xtriage says it:
their moments, N(Z) and the L test, independent of twin laws; the twin
laws the lattice allows, each one's R and H-test fraction; and a summary
that calls the data twinned only where both kinds say so.
  --d-max D         the twin tests' low resolution (10 A, as xtriage's)
  --d-min D         their high resolution (as xtriage chooses it: the
                    finest d to which I/sigma >= 3 in 85 per cent of
                    each shell, never coarser than 3.5 A)
  --max-delta D     twin laws within D degrees' obliquity (3)
  --min-partiality P  observations kept, as mxi correlation's (0.4)
```

## mxi combine

experiment lists joined.

```
usage: mxi combine A.rflx B.rflx [...] [-o combined.rflx]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)

Several runs' files joined into one: every experiment and its models, and
every reflection, renumbered to its experiment in the whole. Typically
integrated data sets, each processed on its own, to go through
mxi symmetry and mxi scale together; mxi split does the reverse.

The same experiment twice (one identifier in two inputs) is refused. The
columns kept are those every input has, shoeboxes included where every
input has them; any other is left out, and named. A DIALS pair is made a
.rflx first by mxi convert.

  -o PATH           where to write (combined.rflx)
  --help, --version
```

## mxi split

an experiment list taken apart.

```
usage: mxi split FILE.rflx [--experiments 0,3,...] [-o PATH | --prefix P]
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)

A file's data sets apart: each data set -- each experiment with a crystal,
with its crystal-less sweep experiment if it has one -- into a file of its
own, P_0.rflx, P_1.rflx, ... numbered by experiment; or, with
--experiments, the ones named together into one. Before indexing, with no
crystals, each sweep. mxi combine does the reverse.

  --experiments I,J  those experiments, by index, into one file
  -o PATH            where that one file goes (split.rflx)
  --prefix P         the files' names, each apart (split)
  --help, --version
```

## mxi convert

.rflx to and from .expt and .refl.

```
usage: mxi convert [options] FILE...
  -j, --threads N   threads for everything this does in parallel; 0, every
                    core this job may use (0)
  Between .rflx -- mxi's own files, one HDF5 file holding the experiment
  list, the reflections or both (docs/rflx.md) -- and the DIALS pair.
  Given a .rflx, writes its .expt and .refl, whichever it holds; given an
  .expt, a .refl or both, writes a .rflx. A .rflx is told by what it is,
  HDF5, not by its name.
  -o, --output PATH      the .rflx to write (from the pair: the first
                         input's name as .rflx); from a .rflx, a .rflx
                         rewritten
  --output-expt PATH     from a .rflx, the .expt (its name as .expt)
  --output-refl PATH     from a .rflx, the .refl (its name as .refl)
  --no-compress          a .rflx with no filter at all, for a reader
                         without bitshuffle-LZ4 (HDF5 filter 32008),
```
